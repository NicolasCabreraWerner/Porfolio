# Portfolio NCW — V2 búsqueda laboral

Versión reorganizada para posicionar el perfil hacia:
- Application Support Engineer
- Technical Support Engineer L2/L3
- Implementation / Solutions Engineer
- AI Automation / Python

## Cambios principales
- Hero y descripción orientados a búsquedas técnicas de mayor seniority.
- Experiencia real ubicada antes de los proyectos.
- Skills reorganizadas por capacidades relevantes para recruiters.
- Corrección del bug de Jinja que mostraba `built-in method items of dict object`.
- Proyectos seleccionados: Zentra Support IA, Taller DB, Sistema gastronómico web, Portal de conocimiento con IA, ProjectFlow Enterprise y Academia de Fútbol SaaS.
- CTA final para oportunidades laborales.
- Se mantiene el CMS/admin y el diseño responsive.
